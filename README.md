# 雅思六点五三周高频词汇计划

这套资料面向雅思目标 6.5，适合目前大约雅思 4.5–5 的学习者，安排为每周 6 天新词、1 天复习。每天 20 个词或词组，三周共 360 个学习词汇单位。前 15 个是主题核心词，后 5 个是巩固基础并向 6.5 过渡的扩展词。选词优先覆盖 Task 2 高频主题、Task 1 图表表达、听力场景和口语 Part 3 讨论。少量核心词会在不同主题中复现，这是为了强化记忆并练习跨题目迁移。

## 前端考试系统

当前 Markdown 适合人阅读，但不适合前端直接消费：词条信息分散在多行文本中，字段名称也依赖中文标签。因此目录中同时提供了结构化数据和静态页面：

- `data/words.json`：通用 JSON 数据，适合后续接入 React、Vue、Anki 转换脚本或数据库。
- `data/words.js`：同一份数据的离线浏览器版本，保证直接双击 `index.html` 也能运行。
- `data/schema.json`：词条字段的 JSON Schema，方便后续校验或扩展。
- `index.html`、`app.js`、`styles.css`：无需构建工具的静态考试系统。

直接双击 `index.html` 即可打开。如果浏览器限制本地脚本，也可以在本目录启动一个静态服务器，例如 `python3 -m http.server 8000`，再访问 `http://localhost:8000/`。

### 后续添加 Week 或词汇

数据格式已经按扩展设计。以后可以：

1. 新建 `week-4.md`，沿用现有词条格式；或者在已有周的某一天继续添加编号。
2. 运行 `python3 build_data.py`，脚本会扫描所有 `week-*.md`，重新生成 `data/words.json` 和 `data/words.js`。
3. 重新打开页面。周选择器会根据数据自动出现 Week 4、Week 5 等新选项，不需要修改 HTML 或 JavaScript。

词条格式的关键是保留以下字段标签：`搭配`、`例句`、`译文`、`词族`、`提醒`。如果未来改用其他数据源，也可以直接按照 `data/schema.json` 生成 JSON。

考试系统支持：

- 选择 Week 起止范围和题目数量
- 词义识别、中文反向选择、拼写输出、语境填空
- 即时反馈：正确答案、搭配、例句、翻译和使用提醒
- 本地保存考试记录、正确率和错题列表
- 一键只练本轮错题
- 间隔复习：答错次日复习，答对按 1、3、7、14、30 天递进
- 每个词记录答题次数、正确/错误次数、连续答对次数和 0–5 级熟练度
- 出题时优先安排到期词、低熟练度词和错题
- 拼写题忽略大小写、空格和连字符，兼容常见英美拼写变体，并允许长词 1 个字符的轻微错误
- 口语 Part 3 与 Task 2 输出练习，保存回答、自评分和日期
- 页面内学习模式：按 Week、Day 和复习状态筛选词条，直接查看词性、音标、释义、搭配、词族、例句和使用提醒
- 学习模式可以把词条标记为“已会”、安排次日复习，或直接调整 0–5 级熟练度
- 单词学习卡片和考试题支持英音（UK）/美音（US）朗读，使用浏览器 Web Speech API 自动选择可用英文 voice

### 数据保存说明

考试进度和输出练习使用浏览器的 `localStorage`，所以刷新页面或关闭后重新打开同一浏览器中的同一地址，数据仍会保留。数据不会上传服务器，也不会自动同步到其他浏览器或设备；使用无痕窗口、清除网站数据或更换浏览器时，本地记录可能不可见。

### 发音说明

英音和美音朗读不需要后端或数据库。页面会把词条传给浏览器的 `SpeechSynthesisUtterance`，并优先请求 `en-GB` 或 `en-US` voice。实际可选的声音由操作系统和浏览器决定；如果系统没有对应的英文 voice，浏览器会使用可用的英语 voice，完全不支持 Web Speech API 时会在按钮旁提示。词条目前保留一个通用 `ipa` 字段，英美音频通过语音引擎区分。

## 每天怎么用

1. **第一遍**：朗读词条，遮住中文回忆词义，再遮住英文回忆拼写。
2. **第二遍**：重点记搭配，不孤立背中文释义。
3. **第三遍**：从当天 20 个词中选 5 个写一个 Task 2 段落，或回答一个口语 Part 3 问题。
4. **复习**：按“当天、第 2 天、第 4 天、第 8 天、第 15 天”复习。复习时先主动回忆，再看答案。

## 记忆标准

- **认识**：看到或听到能理解大意。
- **掌握**：能说出一个常用搭配，并判断词性。
- **会用**：能在自己的句子中准确使用，且没有明显搭配或语法错误。

每天只要求 5 个词达到“会用”，其他词先达到“掌握”。这样比每天机械背大量生词更符合 6.5 的实际需求。

## 已经会的词怎么处理

第一次看当天 20 个词时，给每个词标记 A、B 或 C：

- **A 熟练**：能说出意思、词性和一个自然搭配，并能自己造句。A 词不必重复抄写，把时间用来练习写作或口语。
- **B 认识**：看到能理解，但不会主动使用，或不确定搭配和介词。B 词仍要完整学习。
- **C 陌生**：意思、发音或拼写都不熟。C 词当天朗读三遍，第二天优先复习。

雅思中“认识”不等于“掌握”。例如知道 `impact` 是“影响”，但不会写 `have an impact on`，仍应按 B 类处理。

## 每天 20 个词的时间分配

- 10–15 分钟：复习到期词
- 20 分钟：学习当天 20 个词；A 类快速过，B/C 类重点记搭配和例句
- 10 分钟：从当天词汇中选 5 个写句子或进行口头回答

如果当天到期复习词超过 60 个，或者复习正确率低于 70%，当天新词临时降到 15 个，把剩余 5 个移到第二天。计划的目标是有效掌握，不是机械完成数量。

## 使用提醒

- 不要为了显得高级而强行替换简单词。雅思 6.5 更看重准确、自然和搭配正确。
- 写作中每段使用 2 至 4 个本周词汇就够了，先保证语法和逻辑。
- `access` 通常和 `to` 连用，`impact` 常和 `on` 连用，`contribute` 常和 `to` 连用。把介词一起记住。
- 词条中的例句适合模仿，不建议整句背诵后机械套用。
