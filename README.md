# 雅思六点五十周高频词汇计划

这套资料面向雅思目标 6.5，适合目前大约雅思 4.5–5 的学习者，安排为每周 6 天新词、1 天复习。每天 20 个词或词组，十周共 1200 个学习词汇单位。词条已按标准化英文形式去重，优先覆盖 Task 2 高频主题、Task 1 图表表达、听力场景和口语 Part 3 讨论。

## 前端考试系统

当前 Markdown 适合人阅读，但不适合前端直接消费：词条信息分散在多行文本中，字段名称也依赖中文标签。因此目录中同时提供了结构化数据和静态页面：

- `data/words.json`：通用 JSON 数据，适合后续接入 React、Vue、Anki 转换脚本或数据库。
- `data/words.js`：同一份数据的离线浏览器版本，保证直接双击 `index.html` 也能运行。
- `data/schema.json`：词条字段的 JSON Schema，方便后续校验或扩展。
- `index.html`、`app.js`、`styles.css`：无需构建工具的静态考试系统。
- `db.js`、`vendor/sql-wasm.js`、`vendor/sql-wasm.wasm`：在浏览器内运行 SQLite 的持久化层，不需要启动数据库服务。
- `data/ielts-vocab.sqlite`：可提交到 Git 的词库种子数据库，包含词条表和学习数据表结构。

推荐在本目录启动一个静态服务器，例如 `python3 -m http.server 8000`，再访问 `http://localhost:8000/`，这样浏览器可以正常读取仓库中的 SQLite 种子文件。部分浏览器也能直接双击 `index.html` 打开；如果 `file://` 环境限制数据库文件读取，页面会自动用内置词条数据初始化，但仍建议使用静态服务器。

页面使用静态 hash 路由，因此不同功能可以使用不同链接，不需要后端路由配置：

- `http://localhost:8765/`：首页与词汇考试设置
- `http://localhost:8765/#/speaking`：口语 Part 3 练习
- `http://localhost:8765/#/writing`：Task 2 写作练习
- `http://localhost:8765/#/study`：背单词学习模式
- `http://localhost:8765/#/stats`：学习数据统计

这些链接仍然由同一个静态 `index.html` 提供，刷新或直接打开时会根据 hash 显示对应页面；浏览器的前进、后退也可以切换页面。

### 后续添加 Week 或词汇

数据格式已经按扩展设计。以后可以：

1. 新建下一个 `week-*.md`，沿用现有词条格式；或者在已有周的某一天继续添加编号。
2. 运行 `python3 build_data.py`，脚本会扫描所有 `week-*.md`，重新生成 `data/words.json` 和 `data/words.js`。
3. 重新打开页面。周选择器会根据数据自动出现 Week 4–10 等新选项，不需要修改 HTML 或 JavaScript。

词条格式的关键是保留以下字段标签：`搭配`、`例句`、`译文`、`词族`、`提醒`。如果未来改用其他数据源，也可以直接按照 `data/schema.json` 生成 JSON。

考试系统支持：

- 选择 Week 起止范围和题目数量
- 词义识别、中文反向选择、拼写输出、语境填空
- 即时反馈：正确答案、搭配、例句、翻译和使用提醒
- 本地保存考试记录、正确率和错题列表
- 一键只练本轮错题
- 间隔复习：答错次日复习，答对按 1、3、7、14、30 天递进
- 每个词记录答题次数、正确/错误次数、连续答对次数和 0–5 级熟练度
- 出题时优先安排到期词、低熟练度词和错题
- 拼写题忽略大小写、空格和连字符，兼容常见英美拼写变体，并允许长词 1 个字符的轻微错误
- 口语 Part 3 与 Task 2 输出练习，保存回答、自评分和日期
- 页面内学习模式：按 Week、Day 和复习状态筛选词条，直接查看词性、音标、释义、搭配、词族、例句和使用提醒
- 学习模式可以把词条标记为“已会”、安排次日复习，或直接调整 0–5 级熟练度
- 单词学习卡片和考试题支持英音（UK）/美音（US）朗读，使用浏览器 Web Speech API 自动选择可用英文 voice

### 数据库与保存说明

项目目前不需要后端或正在运行的数据库服务。页面加载 `data/ielts-vocab.sqlite` 作为初始词库，并用 SQL.js 在浏览器内读写 SQLite；学习进度、熟练度、错题、复习日期、考试记录和口语/写作记录会保存为 SQLite 快照，再由 IndexedDB 持久化到当前浏览器。因此刷新页面或重新打开同一地址，数据仍会保留。

`data/ielts-vocab.sqlite` 是仓库中的种子文件，不会被浏览器自动改写。统计面板的“导出 SQLite”会下载当前最新快照；把文件复制回 `data/ielts-vocab.sqlite` 后再提交，才能把某次学习状态保存进 Git。也可以在另一台设备用“导入 SQLite”恢复数据。项目不会上传数据，也不会自动跨浏览器或设备同步。

如果浏览器禁用了 IndexedDB（例如某些无痕或严格隐私环境），页面会退回到兼容性的 `localStorage` 保存方式；这时仍可使用考试系统，但不建议把它作为长期备份。

## 口语与写作练习

首页现在分别进入“口语 Part 3 练习”和“Task 2 写作练习”两个页面，历史记录仍共用 SQLite 的 `practice_records` 表，但按练习类型分别显示。

题目是根据 IELTS 6.5 常见话题和任务结构整理的训练题，不冒充官方真题：

- 口语题按 Part 3 的“直接回答—解释理由—补充例子”组织，覆盖教育、科技、工作、城市等高频讨论主题。
- 写作题按 Task 2 常见的 agree/disagree、discussion、problem-solution 等论证任务组织，提示词帮助练习立场、论证、连接和搭配。

练习题保存在前端静态代码中，不需要后端或联网题库；以后可以直接在 `app.js` 的 `practicePrompts` 中增加题目，保存记录的数据库结构无需改变。

词库变更后可运行 `python3 build_data.py` 生成 JSON/JS 数据，再运行 `python3 build_database.py` 重建 Git 中的 SQLite 种子文件。数据库表包括 `words`、`word_progress`、`exams` 和 `practice_records`，后续添加 Week 不需要修改表结构。

`vendor/sql-wasm.js` 和 `vendor/sql-wasm.wasm` 来自 [sql.js](https://github.com/sql-js/sql.js)，按其 MIT License 分发。

### 发音说明

英音和美音朗读不需要后端或数据库。页面会把词条传给浏览器的 `SpeechSynthesisUtterance`，并优先请求 `en-GB` 或 `en-US` voice。实际可选的声音由操作系统和浏览器决定；如果系统没有对应的英文 voice，浏览器会使用可用的英语 voice，完全不支持 Web Speech API 时会在按钮旁提示。词条目前保留一个通用 `ipa` 字段，英美音频通过语音引擎区分。

## 每天怎么用

1. **第一遍**：朗读词条，遮住中文回忆词义，再遮住英文回忆拼写。
2. **第二遍**：重点记搭配，不孤立背中文释义。
3. **第三遍**：从当天 20 个词中选 5 个写一个 Task 2 段落，或回答一个口语 Part 3 问题。
4. **复习**：按“当天、第 2 天、第 4 天、第 8 天、第 15 天”复习。复习时先主动回忆，再看答案。

## 记忆标准

- **认识**：看到或听到能理解大意。
- **掌握**：能说出一个常用搭配，并判断词性。
- **会用**：能在自己的句子中准确使用，且没有明显搭配或语法错误。

每天只要求 5 个词达到“会用”，其他词先达到“掌握”。这样比每天机械背大量生词更符合 6.5 的实际需求。

## 已经会的词怎么处理

第一次看当天 20 个词时，给每个词标记 A、B 或 C：

- **A 熟练**：能说出意思、词性和一个自然搭配，并能自己造句。A 词不必重复抄写，把时间用来练习写作或口语。
- **B 认识**：看到能理解，但不会主动使用，或不确定搭配和介词。B 词仍要完整学习。
- **C 陌生**：意思、发音或拼写都不熟。C 词当天朗读三遍，第二天优先复习。

雅思中“认识”不等于“掌握”。例如知道 `impact` 是“影响”，但不会写 `have an impact on`，仍应按 B 类处理。

## 每天 20 个词的时间分配

- 10–15 分钟：复习到期词
- 20 分钟：学习当天 20 个词；A 类快速过，B/C 类重点记搭配和例句
- 10 分钟：从当天词汇中选 5 个写句子或进行口头回答

如果当天到期复习词超过 60 个，或者复习正确率低于 70%，当天新词临时降到 15 个，把剩余 5 个移到第二天。计划的目标是有效掌握，不是机械完成数量。

## 使用提醒

- 不要为了显得高级而强行替换简单词。雅思 6.5 更看重准确、自然和搭配正确。
- 写作中每段使用 2 至 4 个本周词汇就够了，先保证语法和逻辑。
- `access` 通常和 `to` 连用，`impact` 常和 `on` 连用，`contribute` 常和 `to` 连用。把介词一起记住。
- 词条中的例句适合模仿，不建议整句背诵后机械套用。
