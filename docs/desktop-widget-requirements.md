# IELTS Vocabulary Lab macOS 桌面词卡需求说明

- 状态：已实现为菜单栏应用管理的透明桌面卡片
- 日期：2026-10-30
- 范围：登录启动和桌面词卡已进入本轮实现

## 目标

让用户登录 macOS 后可以在后台运行学习服务，并能在桌面快速进行一次低摩擦的单词回忆。桌面卡负责短时复习和跳转；完整学习、默写输入和学习记录仍由现有网页承担。

## 用户与场景

- 用户平时打开 Mac 后，希望学习入口已经可用，但不希望浏览器自动弹出。
- 用户看见桌面词卡时，先回忆释义，再主动展开答案。
- 用户需要拼写输入、完整词条信息或复习统计时，直接进入对应网页。

## 范围

### 登录启动

- 菜单栏增加“登录时启动”开关，并显示 macOS 当前登录项状态。
- 首次运行时默认注册为登录项；用户可以从菜单关闭。
- 如果 macOS 要求批准，打开“系统设置 > 通用 > 登录项”并给出说明。
- 登录后静默启动菜单栏应用和本地服务，不自动打开浏览器。
- 菜单栏的“打开学习页面”负责打开浏览器；退出应用时停止本地服务。
- 这是用户登录后的启动，不是登录账户之前的系统引导启动。

### 桌面词卡

- 第一版实现一个约 390 × 326 点的桌面卡片，通过菜单栏应用显示或隐藏，支持 macOS 13 或更新版本。
- 卡片主体使用透明窗口和半透明磨砂材质，让桌面背景透过，同时保证文字可读。
- 用户从菜单栏应用显示卡片，并在卡片中选择 Week 与 Day。
- 卡片固定在桌面层，处于桌面图标上方、普通应用窗口下方；不会置顶遮挡其他应用，也不会覆盖全屏应用。
- 按住卡片顶部“拖动这里移动”区域自由移动；关闭、重新打开和重启后恢复原位置。显示器断开或分辨率变化时，将卡片移回可见屏幕。
- 记住卡片的显示/隐藏状态；重启应用或登录后恢复。首次使用默认显示卡片。
- 1.9（14）已嵌入 WidgetKit 扩展并完成 Xcode 构建、开发签名、安装和桌面添加。系统网格及右键编辑由 macOS 管理；原自由拖动桌面卡片作为独立模式保留。见[系统小组件接入](./native-widget-setup.md)。
- 卡片从打包在应用内的 `data/words.json` 读取只读词库，每次展示当天的一张词卡。
- 当天词汇按词库顺序分批，每批最多 10 个词；20 个词的学习日会分成两批。
- “换一批”切换到下一批并从该批第一个词开始；到最后一批后循环回第一批。上一词/下一词只在当前批内循环。
- 卡片窗口可见且未被其他窗口遮挡时，每 60 秒自动切换到当前批的下一词；隐藏或被遮挡时暂停，重新显示后重新计时。手动切词、换批或选择日期后也重新计满 60 秒。检测依据为上层窗口边界的重叠，每秒检查一次；透明覆盖层可能导致保守暂停。
- 默认展示英文、音标、词性和“先回忆释义”提示；中文释义默认收起。
- “显示释义 / 收起释义”用于控制答案可见状态；“下一词”切换当前批词条。
- “上一词”可返回当前批上一条；首词继续向前会循环到该批最后一条。
- 点击“网页默写”打开学习网页并定位到对应 Week/Day。完整输入、答题反馈与保存仍在网页进行。
- Week、Day、批次、当前词和释义展开状态会保存在本机偏好设置中，重启后恢复。
- 卡片显示/隐藏和切词状态只属于展示状态，不代表掌握度或复习记录。

## 打开与关闭机制

“打开/关闭”分为两个不同动作，界面不把它们混成一个开关：

1. **显示或关闭桌面卡片**：由菜单栏应用管理。用户从菜单栏选择“显示桌面单词卡”；再次点击“隐藏桌面单词卡”或卡片右上角的关闭按钮即可收起。关闭卡片不会退出菜单栏应用、删除词库或清除学习记录。
2. **展开或收起答案**：由卡片内部按钮管理。默认隐藏中文释义；按“显示释义”展开，再按“收起释义”恢复遮挡。点击“网页默写”进入网页训练。

当前版本是由菜单栏应用控制的原生桌面窗口，不需要在 macOS 小组件图库中添加。菜单栏和卡片右上角都能收起卡片；卡片不提供自由文本输入。

## 数据与技术边界

- 当前网页学习进度保存在浏览器 IndexedDB 中。桌面卡片不能直接读取浏览器的 IndexedDB。
- 卡片读取应用包内的只读词库，不依赖云端或联网题库。
- 答案显示、切词和 Week/Day 选择保存在主应用的本机偏好设置中；不与网页学习进度或熟练度共享。
- 若未来要从卡片记录“会了/需复习”并同步网页统计，需要再设计共享的学习数据源，例如 App Group SQLite 加本机 API，并迁移现有浏览器数据。这属于后续阶段，不纳入首版。
- 桌面卡片由 SwiftUI/AppKit 构建并由菜单栏应用控制；用户无需在 macOS 小组件图库中添加。
- 网页支持 Week/Day/word 深链；原生应用用 URL scheme 把参数传给本机学习页面。卡片也可通过 `ieltsvocab://card` 打开或关闭。

## 非目标

- 不将网页完整嵌入桌面卡片。
- 不在卡片内完成键盘默写、长篇例句编辑或口语/写作练习。
- 首版不展示到期复习数、熟练度、错题数和学习统计。
- 不引入云端账户或远程数据库。

## 产品默认决策

- 登录启动首次默认为开启，用户能从菜单栏关闭。
- 登录启动只启动服务，不自动打开浏览器。
- 卡片采用约 390 × 326 点的尺寸、手动选择 Week/Day、释义默认隐藏，桌面内容透过半透明底板可见。
- 卡片显示/隐藏由菜单栏管理；答案由卡片内按钮展开/收起。
- 卡片显示且未被遮挡时每分钟自动切词；每批最多 10 词，手动按钮可轮换批次。
- 卡片只读词库，不改变学习进度。
