关于保存

正式版关闭窗口、退出或重启电脑后，已保存的学习记录仍留在本机。

词库与语言资源随 App 分发；学习数据库独立保存，升级应用不应覆盖。口语音频作为附件保存，完整备份一起带走。

备份文件可自行版本管理；运行中的临时数据库文件不作为备份。文章和录音也会包含在完整备份里，分享前可查看内容清单。

统计口径与原型边界

新学词按稳定词条 ID 去重；答题次数与新词数分开。首次正确率不包含同题重试；近似拼写需要改正后才算通过。

学习时长只计活动练习时间；暂停、后台空闲及桌面自动展示不累积学习时长。口语回答、写作文章与修订次数分别统计，不折算考试分数。

统计为独立样例，不与前四阶段原型共享状态。设置、语言切换、备份恢复和系统设置均为演示；没有访问 SQLite、麦克风或登录项。刷新恢复初始状态。

重置本页演示记录？

统计变为空状态，词库仍保留。可以立即撤销，也可以刷新页面恢复初始演示数据。其他页面、学习数据库和正式 App 不受影响。

从哪里打开词卡？

透明桌面词卡：正式 App 的菜单栏 → 显示桌面词卡；可拖动位置，不遮挡普通窗口。关闭后仍可从菜单栏显示。

系统小组件：桌面右键 → 编辑小组件 → 搜索 IELTS → 添加。网格与右键编辑由 macOS 管理，移除也在系统桌面完成。

系统小组件的刷新与交互由系统调度，不能保证严格每 60 秒切词；“未被遮挡时每分钟轮播”属于独立透明桌面词卡。此原型不会添加、移除或修改系统小组件。
