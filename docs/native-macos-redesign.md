# macOS 原生学习界面评估

## 结论

原生重构有价值，特别适合把 Mac App 从“网页装进窗口”提升为桌面学习工具。不过，更换技术本身不会自动让界面更快或更好看。当前交互与词汇数据主要由同一份 HTML/JavaScript 提供，App 用 `WKWebView` 离线加载；原生 Swift 负责窗口、菜单栏、Widget、语音和数据库桥接。

SwiftUI 能更自然地接入 macOS 导航栏、窗口工具栏、菜单命令、快捷键、系统字体与材质、焦点管理、输入法和无障碍能力。点击反馈、页面切换和文字输入可直接在原生视图中更新，也更容易避免 WebView 的视觉割裂。语音和 SQLite 已有原生接口，可以继续使用。

性能要按实际场景看：本应用主要显示文字和选项，WebKit 并没有明显的渲染负担；原生界面带来的主要收益是操作一致性、键盘/窗口体验和设计控制，不是词汇数据访问速度的大幅提升。数据库读写、打包的 6000 词和语音延迟各自需要独立测量。当前学习页的“一两秒等待”也应先用启动、数据库、DOM 更新和语音请求的耗时记录定位，避免把独立瓶颈误归因于 WebView。

## 推荐方向

2026-10-31 用户确认：后续产品只迭代 macOS 原生 App，网页版停止功能迭代，保留现状作为旧版本参考。原生 App 采用 SwiftUI 重新设计学习流程，包括词汇、复习、考试、统计、口语和写作，不按旧网页逐页复制。

词库、审核后的多语语言包、稳定词条 ID 和现有 SQLite 数据结构作为迁移基础。当前原生数据库桥只负责读取和保存网页产生的 SQLite 快照；正式开发时需要设计原生查询、写入和迁移层，不能把现有桥误认为已完成的原生数据库访问层。旧网页复习规则可作为兼容性测试依据，不再承担新功能的双端同步迭代。

独立 HTML 原型继续用于快速核对布局和交互，不代表继续迭代网页产品，也不接入当前学习数据库。全部阶段原型逐一确认后，才开始原生 App 的统一开发；统一开发内部可以按模块实现和验收。

## 原型切片

[打开 macOS 学习界面原型](http://localhost:8765/docs/native-macos-prototype.html)

原型包含：

- 侧边栏进入“今天、每日训练、学习进度”，并可直接切换认词、默写、语境练习。
- “今天”显示当天目标、待复习数量、三段式学习路径和部分词表。
- 训练页可切换模式、显示或隐藏中文提示、输入拼写、查看答案、选择答案、听 UK/US 发音，并显示即时反馈。
- ←/→ 切词、Enter 检查、Escape 返回；答错的词会在原型状态中进入复习提示。
- 反馈短促、进度可见；不采用分数轰炸、金币、弹窗连播等容易打断专注的设计。

这是用于确认信息架构、页面密度和交互节奏的静态原型。词条和统计是演示数据，不连接 SQLite、语音原生桥、Widget 或现有网页学习状态，也没有修改或替换当前 App。

阶段一原型覆盖“今天、每日训练、学习进度”的初步交互。它不包含口语或写作页面，也未完整呈现词库管理、复习队列和自定义考试；这些模块由后续阶段单独原型确认。

### 阶段二：词库、复习与自定义考试

[打开阶段二原型](http://localhost:8765/docs/native-macos-vocab-prototype.html)

当前可交互范围：

- 按周、累计学习日、熟练度和关键词筛选示例词；查看音标、词性、释义、搭配、例句、词族和提示。
- 调整演示熟练度和复习日期；查看到期词与最近错词队列。
- 指定周范围、累计学习日、题量和题型，优先抽取到期词；首次答错后安排一次稍后回练。末题错词会留到下一轮。
- 输入题支持拼写比较；结果页区分首次正确率、错题回练和待巩固词。可从结果页再次练错词。

此原型只内置 12 个跨 Week 1–3 的示例词，组卷题量受匹配样例限制；发音使用浏览器语音演示。熟练度、答案、复习日期均只存于当前页面内存，刷新即恢复初始状态。没有连接数据库，也没有更改正式 App。

### 阶段三：口语练习、计划与自评

[打开阶段三口语原型](http://localhost:8765/docs/native-macos-speaking-prototype.html)

- 独立呈现 Part 1 日常问答、Part 2 个人陈述与 Part 3 深入讨论；按原定十周主题切换。
- 每周 3 道 Part 1、1 张带提纲的 Part 2 题卡、3 道 Part 3，共 70 道自编示例题；不是官方真题、机经或预测。正式题库规模后续确定。
- 可练单题或一组。Part 2 演示 60 秒准备 → 最多 120 秒回答；Part 1 / 3 的 45 / 90 秒仅为单题训练参考，不是考试单题限时。页面标明正式考试各 Part 时长，附官方说明来源。
- 题目默认英文，可展开中文题意；关键词便笺、表达提示默认不提供完整答案。便笺属于训练辅助，不模拟严格考试条件。
- 录音、暂停、结束、回放、进度拖动与倍速均为状态演示，不调用麦克风、不产生真实音频、不转写或自动评分；提供快进便于评审。
- 四维自评：流利度与连贯性、词汇运用、语法多样性与准确性、发音。不折算雅思分数。每次保存一个改进点，可查看、编辑和重练同题。
- 记录仅在本次页面内存中保留。没有连接 SQLite、修改正式 App 或迭代旧网页产品。

阶段三待用户确认：题目列表和练习区布局、准备/回答/回听流程、自评负担、十周练习节奏。确认之后再出写作原型；全部阶段确认后统一进行 SwiftUI 开发。

### 阶段四：Academic Writing Task 1 / Task 2

[打开阶段四写作原型](http://localhost:8765/docs/native-macos-writing-prototype.html)

- 沿用十周写作主题，每周提供 1 道 Task 1 和 1 道 Task 2，共 20 道自编示例题。当前题量用于确认练习流程，不是正式题库规模；题目不是官方真题、机经或预测。
- Task 1 覆盖柱状图、折线图、表格、流程图、地图和饼图。数值为明确标注的虚构示意数据，可展开数据表与放大图表；Task 2 提供议论文题目和中文题意，不配图。
- 可选 Task 1（至少 150 词 / 建议 20 分钟）、Task 2（至少 250 词 / 建议 40 分钟）、60 分钟整套练习或自由写作。计时可暂停；达到建议时长后会提醒，不自动交卷。Task 2 权重更高已标明。
- 编辑区提供提纲、英文词数估算、段落数、字号调整和专注布局。Task 1 与 Task 2 使用各自适用的四项官方评分维度自评，不打分或预测分数。
- 初稿与每次另存的修订稿独立保留，可以切换对照版本、前后并排比较、补一条修改说明，也可回到编辑继续修改。
- 草稿、文章和自评只存于当前页面运行内存，刷新或关闭页面会清空；不连接 SQLite，不修改正式 App。

阶段四已由用户在 2026-11-01 确认。继续制作阶段五；全部阶段确认后再统一原生开发。

### 阶段五：统计、设置、数据管理与桌面入口

[打开阶段五原型](http://localhost:8765/docs/native-macos-system-prototype.html)

- 统计支持近 7 / 28 天、每日学习时长详情、按词条去重的新学数量、首次正确率、熟练度快照、复习预估与口语/写作/修订次数。全为独立示例；当前快照不随日期筛选变化。
- 学习设置保留每日 20 词默认目标、三段式顺序、近似拼写提示和错词回练。发音设置演示英美口音与语速，不播放真实声音，也不承诺已达到某个延迟指标。
- 六种学习母语：中文及日、韩、法、西、阿。按当前语言包清单如实标示五包为 draft；少量样例仅演示释义切换与阿拉伯语 RTL，不表示翻译审核或完整界面本地化已完成。
- 切换母语建立新的学习档案，原语言记录不迁移到新语言。用户可在切换前主动导出备份；切换须明确确认并清空当前原型进度。这对应用户“通常只切换一次，不需要保留原语言学习记录”的产品偏好。
- 数据页演示完整备份清单、恢复预览、不兼容版本阻断、CSV 预览与可撤销重置；不读取或写入文件。正式设计为包含 SQLite 一致性快照、设置和录音附件的备份包，数据库不需要独立服务。
- 透明桌面词卡支持场景内拖动、释义状态保持、左右切词、每批 10 词、轮内去重、跨轮避免紧邻上一批、隐藏/重新显示、遮挡暂停及一分钟快进。只内置每周 30 词（两周共 60 词）用于核对，正式版使用整周词库。
- 系统小组件和独立透明词卡分别展示。严格每分钟的可见轮播属于独立桌面词卡；系统小组件刷新由 macOS 调度，不保证每分钟，也不在原型中修改系统网格或右键菜单。
- 设置含浅/深色、跟随系统、文字大小、减少动画、登录启动和关闭主窗后保留菜单栏；系统设置开关均为演示。各阶段增加可见跳转入口与页面深链，但独立原型的状态不会跨页同步。

待核对：统计重点、母语切换提醒、备份/恢复流程、桌面词卡的两种形态和设置密度。阶段五确认后汇总全部原型需求，再统一开发 SwiftUI，不提前覆盖当前安装的 App。

## 主要成本与风险

- 不再维护两套迭代界面；原生端仍需承担 SwiftUI 页面、无障碍和键盘操作的开发及验证成本。
- 将既有 JavaScript 学习规则迁移到 Swift 时，可能产生错题、复习日或熟练度差异；应提取兼容性案例验证迁移结果，后续以原生规则为维护对象。
- 若把网页功能按页面机械搬运，界面仍会显得臃肿。原生重构应先调整导航与任务流程，再迁移功能。
- App Store 版本、开发版和网页资源的构建/安装流程需要分清，避免原型或网页资源覆盖原生版本。

## 已确认的设计决策

- 原生 App 以“今天”为主要入口。
- 每日训练默认采用“认词义 → 默写拼写 → 语境应用”，允许随时切换。
- 保持当前原型的 macOS 原生工具感、留白和配色，趣味交互保持克制。
- 网页版停止迭代；独立原型仍可使用 HTML 演示。
- 口语和写作纳入整体原生化范围，分别出原型确认。
- 先分阶段确认全部原型，再统一开发；当前不修改或替换正式 App。
