TEN-WEEK PATH

每周一个话题，反复开口

学习日分开练三个 Part，周末回听与串联。

周一 / 周二Part 1 · 熟悉话题直接回答，补充原因或例子
周三 / 周四Part 2 · 讲一段经历列关键词，完成一次连续陈述
周五Part 3 · 解释与比较观点、理由、例证和限定
周末回听 → 重练 → 串联重练最薄弱题，第十周集中整合

这是学习节奏建议，不是每日固定题量。当前原型每周提供 3 道 Part 1、1 张 Part 2 题卡、3 道 Part 3 题，供核对流程。

题目与计时说明

题目是按十周主题编写的练习内容，不是官方真题、机经或预测。题量用于确认原型体验，不代表正式版题库规模。

正式考试：Part 1 为 4–5 分钟；Part 2 准备 1 分钟，陈述 1–2 分钟，该部分共 3–4 分钟；Part 3 为 4–5 分钟。这些是部分时长，不是每道题的限时。

本应用单题练习参考：Part 1 为 45 秒、Part 3 为 90 秒，达到参考时间后可以继续。这是训练安排，不是考试规定。Part 2 演示 60 秒准备和最多 120 秒陈述。

原型不调用麦克风、不保存真实音频、不做语音识别或自动评分。正式原生 App 的录音权限、音频保存与回放会在统一开发时实现。
